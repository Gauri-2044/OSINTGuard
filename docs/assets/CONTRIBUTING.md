# Contributing to OSINTGuard

Thank you for your interest in contributing to OSINTGuard! 🛡️

OSINTGuard is an open-source project focused on helping users identify
potentially sensitive information before sharing it publicly.

We welcome contributions that improve the project's functionality,
security, documentation, testing, and usability.

---

## Getting Started

### 1. Fork the Repository

Fork the OSINTGuard repository to your GitHub account.

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/OSINTGuard.git
cd OSINTGuard
```
### 3. Create a Branch

Create a separate branch for your work.
```bash
git checkout -b feature/your-feature-name
```

## What You Can Contribute

Contributions can include:

- Improving entity detection
- Adding new OSINT exposure rules
- Improving risk detection
- Adding or improving tests
- Improving the user interface
- Fixing bugs
- Improving documentation
- Improving accessibility and usability
- Improving security and privacy
